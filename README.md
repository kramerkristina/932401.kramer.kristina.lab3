## Что реализовано в коде

### 1. Flexbox-верстка
*   **Навигационное меню:** Горизонтальное меню (`<nav>`), построенное на Flexbox.
*   **Топ-сериалов:** Карточки с постером, названием, жанром и годом выстроены в адаптивный ряд с помощью свойств `display: flex` и `flex-wrap`.

### 2. CSS Grid-верстка
*   **Любимые режиссёры:** Карточки с фото, именем и знаковым фильмом расположены с помощью `display: grid`. Использован шаблон `grid-template-columns: repeat(2, 1fr)`, образующий сетку 2×2.

### 3. Адаптивность (Медиа-запросы `@media`)
Настроены брейкпоинты для корректного отображения на разных устройствах без горизонтальной прокрутки:
*   **Десктоп:** 3 колонки для карточек сериалов, 2 колонки для режиссёров.
*   **Планшет (до 1024px):** Карточки сериалов перестраиваются в 2 колонки, режиссёры остаются в 2 колонках.
*   **Мобильные устройства (до 768px):** Все блоки (и Flex, и Grid) выстраиваются в 1 колонку (`flex-direction: column` и `grid-template-columns: 1fr`).

### 4. Семантика и стандарты
*   Использованы семантически верные теги (`<nav>`, `<section>`, `<article>`).
*   В блоке режиссёров применён тег `<picture>` с вложенными `<source>` для поддержки современных форматов изображений (`.webp`).
*   Обеспечена высокая контрастность текста (светлый шрифт на темном фоне ≥ 4.5:1).
